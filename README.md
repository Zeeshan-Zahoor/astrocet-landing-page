# 🚀 AstroCET Landing Page

A modern, animated landing page for **AstroCET** — the space robotics community at College of Engineering Trivandrum.

---

## 🌐 Live Demo

👉 https://astrocetlanding.netlify.app/

---

## ✨ Features

* 🌌 **Hero Section**
  Animated gradient title, rotating subtitles, floating star background, scroll indicator

* 📖 **About Section**
  Split layout with mission & vision cards + animated statistics

* 📅 **Events Section**
  Upcoming & past events with glassmorphism cards and expandable view

* 🛰️ **Space Spotlight**
  Interactive space facts carousel with animated planet & orbit system

* 👥 **Team Section**
  Department-wise team display with member cards, social links & lazy loading

* 🎯 **Smooth Scrolling**
  Powered by Lenis for seamless navigation

* 📱 **Fully Responsive**
  Optimized across mobile, tablet, and desktop devices

* 🎨 **Modern UI Design**
  Glassmorphism + space-themed gradients (purple/cyan)

---

## 🛠️ Tech Stack

* **Frontend:** React 18 + Vite
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion, Lenis
* **Icons:** Lucide React, React Icons
* **Deployment:** Netlify

---

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/Zeeshan-Zahoor/astrocet-landing-page.git

# Navigate into project
cd astrocet-landing-page

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
